# 🐉 Dragon Prime: Fusion TCG

Welcome to the official GitHub repository and player mechanics guide for **Dragon Prime**, a sustainable card evolution and crafting TCG hosted on the **WAX blockchain**.

---

## 🌟 Core Game Loop & Philosophy
Dragon Prime is built around player progression, strategic card burning, and community evolution. Instead of relying on random pack filler, every duplicate card has tangible utility through our multi-tier evolution path.

- **Collection Name:** `dragonprime1`
- **Schema:** `dragonsandeggs`
- **Primary Resource:** Mysterious Dragon Essence (acquired via primary drops).

1. **Hatchery Blend:** Burn `4x Mysterious Dragon Essence` ➔ Receive `1x Dragon Egg`
2. **Awakening Blend:** Burn `3x Dragon Eggs` ➔ Receive `1x Bronze Dragon Whelp`
3. **Silver Tier Evolution:** Burn `3x Bronze Dragon Whelps` ➔ Receive `1x Silver Dragon Whelp`
4. **Gold Tier Evolution:** Burn `3x Silver Dragon Whelps` ➔ Receive `1x Gold Dragon Whelp`
5. **Platinum Apex Evolution:** Burn `3x Gold Dragon Whelps` ➔ Receive `1x Platinum Dragon Whelp` *(Strictly capped at 1,000 max mints)*
