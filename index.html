Long before the realms divided, the Prime Wyrms ruled the cosmos, their vitality bound to elemental metals deep within the earth. WAX Cloud Wallet JS Integration Code

waxjs SDK

To upgrade this simulator from mock local state to real WAX blockchain transactions on AtomicAssets, include the official waxjs script library: 

<script src="https://unpkg.com/waxjs@1.5.0/dist/waxjs.js"></script>
<script>
  const wax = new waxjs.WaxJS({ rpcEndpoint: 'https://wax.greymass.com' });

  async function loginWAXWallet() {
    try {
      const userAccount = await wax.login();
      console.log("Connected WAX Wallet:", userAccount);
    } catch (err) {
      console.error("Wallet Connection Error:", err);
    }
  }
</script>
